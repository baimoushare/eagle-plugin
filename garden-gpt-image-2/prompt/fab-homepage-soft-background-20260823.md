# FAB 首页背景化处理提示词

请以我提供的 FAB 数字资产市场网站首页截图为唯一构图参考，进行“背景化、模糊化、简化”的图像编辑，输出一张适合网站封面或页面背景使用的宽屏 16:9 视觉背景。

保留原图最重要的识别特征：深黑接近炭黑的整体界面底色；顶部横向导航栏；左侧窄版垂直导航区；中上部的大型主视觉横幅；中下部连续排列的内容区块、分类区块和商品卡片网格；底部较暗的页脚区域。保留原图的色彩关系和信息层级：黑灰色 UI 框架作为底色，主视觉区域使用低饱和的米白、暖棕、灰绿色，商品卡片中保留少量蓝色、紫色、橙色、青绿色和黄色作为稀疏的彩色视觉锚点。

将所有文字、价格、按钮、评分、图标和商品细节处理成不可读但有网页界面暗示性的柔和形状；不要生成清晰文字，不要出现乱码，不要突出任何单个商品或人物。对整体画面进行中等程度的景深虚化、高斯模糊和轻微磨砂玻璃质感处理，让人能一眼看出这是数字资产商城/创意资源平台首页，但无法阅读具体内容。卡片边界、横向分区和侧边栏仍然清楚可辨，视觉节奏整齐，信息密度明显降低，画面简洁、克制、现代、高级。

画面应保持平整的网页界面视角，不要透视变形，不要变成手机界面，不要变成抽象渐变，不要加入新的大标题或宣传文案。整体对比度中低，边缘柔和，中心区域略明亮，四周适度压暗，为后续叠加网站标题、按钮和前景内容预留干净的留白。

风格关键词：dark editorial web background, simplified marketplace homepage, soft-focus UI blocks, muted charcoal interface, restrained colorful content cards, subtle frosted glass, premium digital asset platform, low information density, clean modern composition, atmospheric blur, background-ready.

负面约束：清晰可读的文字、乱码、过多小字、复杂图标、锐利商品细节、密集卡片、强烈霓虹、赛博朋克、鲜艳渐变、白色后台管理系统、手机 App 布局、透视倾斜、重复 logo、错误品牌文字、过度模糊导致区块消失、明显噪点、杂乱构图。

建议使用图生图/参考图编辑模式，参考强度约 35%–50%，优先保留原图布局与色彩，不要完全重绘页面。
